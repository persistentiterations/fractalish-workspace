# Fractalish Workspace

This repository is a review-ready working library for the Fractalish family of projects.

## Start here

1. Read [`PROJECT_MAP.md`](PROJECT_MAP.md).
2. Choose one project rather than searching the entire repository at once.
3. Treat files under `library/` as collected evidence, not automatically as canonical releases.
4. Record canonical-file decisions in the corresponding project README.
5. Consult `reports/` before looking for missing archives, generated files, or duplicates.

## Important status rule

Presence in this repository means a file may be useful. It does **not** mean every claim is verified or every version is current. Jim's team should identify the strongest version, document why it was selected, and preserve provenance when consolidating work.

## Repository policy

- Do not commit generated caches or dependency folders.
- Do not add installers.
- Do not add large experimental outputs directly to Git.
- Do not rename an old file to imply that it is canonical.
- Use branches and pull requests for consolidation work.
- Prefer one documented canonical entry point per project.

## For ChatGPT and other AI systems

Use `PROJECT_MAP.md` as the routing document. Do not infer that a file is authoritative merely because its filename contains words such as `final`, `fixed`, `stable`, or a higher version number. Compare related candidates and cite exact paths when summarizing them.
