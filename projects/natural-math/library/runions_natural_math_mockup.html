Natural Math translation

Auxin source → RESOURCE / BEACON. A bounded point embedded in the current leaf domain.
Vein segment → deposited NODE. It remains as persistent morphology and stores a parent link.
Nearest vein search → local SENSE. A source may influence only nodes inside the selected horizon.
Growth toward sources → EXTEND. A node averages directions to its locally assigned sources and deposits one child.
Source removal → CONTACT / consumption. A reached source disappears inside the kill radius.
No assigned source → CONSERVE. The node deposits nothing that cycle.
Finite sources and step cap → DYNAMIC LIMITS. Growth cannot continue indefinitely.

Compatibility receipt

Compatible at the architectural level: local sensing, local extension, persistent deposition, finite sources, and explicit termination. Not yet compatible with the strict frozen integer base: this visualization uses continuous coordinates and distance calculations. A later grid version can quantize positions, directions, and radii to integers.
