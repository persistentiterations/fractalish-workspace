# Arena loop v0.1 — materializer → hotseat (local only)

**One-command flow:** from this package directory run `python run_arena_v0_1.py` (optional path to a teaching-subset `.symlan` file; default is the HAL §7 example inside `materializer_v0_1.py`). The script materializes a `PlayableState`, writes `last_playable_state.json` plus a `file://`-safe companion `last_playable_state.js`, prints the canonical JSON SHA-256, and opens `hotseat_play_surface_v0_1.html?load=last` in your default browser so the hotseat loads that state (button **Load last materializer output** does the same). If auto-open fails, open the printed `file://` URL, or run `python -m http.server 8765` in this folder and visit `http://127.0.0.1:8765/hotseat_play_surface_v0_1.html?load=last`. **Claim boundary:** offline prototype bootstrap only — reuses the accepted materializer and hotseat without changing HAL geometry or SymLan gates; not an IDE, full compiler, production runtime, or network multiplayer; mock/teaching discovery remains distinct from substrate-earned vocabulary.
